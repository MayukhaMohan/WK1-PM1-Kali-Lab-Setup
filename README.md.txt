# WK1-PM1: Kali Linux Lab Setup

## Project Overview
This project covers the setup of a cybersecurity lab environment using Oracle VirtualBox and Kali Linux.

## Objectives
- Configure a VirtualBox NAT Network.
- Set up Kali Linux with the required IPv4 address.
- Verify internet connectivity.
- Configure a shared folder between Windows and Kali Linux.
- Enable shared clipboard and drag-and-drop.

## Lab Configuration
- **Virtualization Software:** Oracle VirtualBox
- **Operating System:** Kali Linux
- **Network Type:** NAT Network
- **Network Subnet:** `10.0.0.0/24`
- **Kali Linux IPv4 Address:** `10.0.0.2/24`
- **Shared Folder Name:** `downloads`
- **Internet Connectivity:** Tested using `ping -c 3 google.com`
